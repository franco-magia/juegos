# Franco Magia Arcade

Todos los juegos de Franco en un solo lugar: **https://francosandes.com/juegos/**

- `index.html`: el portal con todos los juegos.
- `franco-magia/`: la aventura completa (Scratch + TurboWarp). Con `?ir=nombre` abre directo un minijuego (por ejemplo `?ir=huerta`).
- `3d/`: los juegos 3D (motor WebGL propio). Con `?juego=nombre` abre directo un juego (por ejemplo `?juego=zombis`).
- `img/`: las imágenes de las tarjetas.

Hecho por Franco.
